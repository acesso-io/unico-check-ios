# unicocheck-ios

SDK de captura da unico | check para iOS. Documentação de integração: https://devcenter.unico.io/idcloud/integracao/sdk

## Instalação

Pelo Swift Package Manager: pacote `https://github.com/acesso-io/unico-check-ios`, produto `unicocheck-ios-spm`.

## Descontinuação do CocoaPods

O trunk do CocoaPods fica somente leitura em 2 de dezembro de 2026. Esta é a última versão do `unicocheck-ios`
publicada no CocoaPods; as próximas saem só pelo Swift Package Manager. As versões já publicadas continuam
instalando com `pod 'unicocheck-ios'`, mas para receber versões novas migre para o Swift Package Manager.
